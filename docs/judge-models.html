Judge settings and prospective method · Updated October 27, 2026

Judge models

CREST uses GPT-6 Astra and Gemini 4 Argon, both at high reasoning/thinking. Each compares complete answers labeled A and B in both orders and returns one overall A/B winner. The October 27, 2026 protocol v3 revision applies to future judging: it defaults to the revised shared rubric, screens comparative explanations, and uniformly removes URL destinations from presentations while retaining meaningful citation labels and raw originals. This reduces explicit provenance cues; it does not ensure complete blinding. Existing runs retain their frozen prompts, presentations, settings, and results; see the interpretation limits. The panel was chosen for capability, without evidence that it is optimal for this rubric.

The existing rubric file-path setting can select the revised default or the preserved original binary wording. Both choices use current presentation and explanation-quality safeguards; the choice does not restore historical calls. Rubric changes affect judgment-cache identities and reuse generated answers. Judge costs are additional

There are 300 planned calls per judge in a complete 50-question experiment. Output allowance includes reasoning/thinking; it is headroom, not predicted usage. Judge spending is separate from the $5-per-answer generation targets.

Illustration only: at 10,000 uncached input and 3,000 billed output tokens per call, 300 calls to each judge cost about $90 at October rates, before retries or cache-write differences. Actual totals depend on observed usage; this is not a forecast or spending cap. The adapters price both selected models, handle queued jobs, and retain unknown costs when essential usage is missing.

Different models, shared limitations

The researchers use Sol/Luna for Caesar, Sol for native OpenAI research, and Google's managed Deep Research agent. Using Astra and Argon avoids identical researcher/judge model IDs but does not establish independent errors or remove provider/style preferences. Keep the common panel, per-judge views, disagreement, and swapped-order diagnostics. No empirical human or domain-expert validation of this rubric or panel has been performed. Human calibration remains necessary for stronger claims; see the method's interpretation limits.
