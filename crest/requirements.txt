# pair becomes a real conflict, so this file lists ONLY what the root manifest lacks.
# (An earlier attempt to express this with pip's `-r crest/requirements.txt` in the ROOT file broke
# `pip install .` outright: setuptools does not expand -r and passed the literal line through as a
# PEP 508 specifier.)

# The first two are LOAD-BEARING FOR CORRECTNESS, not convenience: harness/run_crest.py now RAISES
# without them rather than warning, because a missing jsonschema silently disabled item validation
# and a missing pyyaml silently re-admitted every quarantined item -- while ci_check.sh still printed
# "OK 50 items load and validate".
