# Archived material

Historical code, documents, and source snapshots; not the active runtime.

- [index.html](index.html): archive map and provenance notes.
- `reference/`: earlier project overviews, dependency lists, and rubric records.
- `research/`: study documentation, paper sources, question records, and local run data.
- `runtime/`: superseded harness, judging, configuration, and analysis code.
- `entrypoints/`: former stage wrappers retained for reference.

Historical reports and run artifacts are immutable; do not rewrite or rename them.
`research/result/` is ignored local data and may be absent from a fresh clone.
