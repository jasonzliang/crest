\section{The CREST Benchmark}
\label{sec:design}

\paragraph{Construct.} We adopt the standard definition of creativity---an artifact must be both \emph{novel} and \emph{useful/appropriate} \citep{runco2012standard,sternberg1999concept}---augmented with Boden's third criterion, \emph{surprise} \citep{boden2004creative}, giving the New/Useful/Surprising (N/U/S) rubric---each axis scored $1$--$10$, an output counting as creative only if all three clear a threshold. Crucially, \emph{Useful} functions as a factual-grounding check on \emph{New}, and \emph{Surprising} is expectation-violation \emph{conditioned on correctness}, which distinguishes CREST from novelty-only metrics (\S\ref{sec:related}). This N/U/S operationalization is the established construct---from the standard creativity literature and from recent deep-research-agent creativity evaluations \citep{caesar2026}---not a metric we introduce; it is defined independently of any evaluated agent.

\paragraph{Categories.} Creativity is not monolithic. CREST scores N/U/S across five categories that instantiate distinct creative processes from the literature: \textbf{C1 Constrained} and \textbf{C5 Open-Ended} correspond to Boden's \emph{exploratory} (search within a fixed space) and \emph{transformational} (rewriting the space) creativity; \textbf{C3 Cross-Domain} instantiates \emph{combinational} creativity, grounded in structure-mapping theory, in which cross-domain synthesis is relational alignment under the systematicity principle \citep{gentner1983structure,falkenhainer1989sme}; \textbf{C2 Counterfactual} is grounded in the rational imagination, where ``what-if'' reasoning is systematic over a causal model \citep{byrne2005rational}; \textbf{C4 Meta-Creativity} captures reflective, space-altering creativity.

\paragraph{Items.} CREST ships 50 expert-authored challenges---10 per category---across six domains (biology/medicine, materials/chemistry, economics/business, law/policy, engineering, arts/humanities; 8--9 each). Each challenge requires deep multi-source synthesis (never a single lookup) and ships with (a) a \emph{dated known-answers list} (the baseline against which \emph{New} is judged), (b) checkable \emph{hard rules} (the reference for \emph{Useful}), and (c) an \emph{expert baseline} answer (the reference for \emph{Surprising}). Every item is labeled by isolated axis, domain, and pre/post-training-cutoff.

\paragraph{Open prompts, judge-side rubric.} A design choice we state explicitly: the \emph{agent-facing} prompt is short and open (median $\sim$110 words) and poses only the creative question. All axis-isolation and anti-contamination machinery---the hard rules, dated known-answers, and expert baselines---lives \emph{judge-side} and is never shown to the agent. This preserves creative headroom and avoids over-steering the agent toward a target answer, while keeping grading reproducible and axis-isolated.

\paragraph{Contamination and length controls.} Entrants run under their \emph{provider-native web search} (no separate search key); a \emph{frozen, dated corpus snapshot} queried through a \emph{single shared retrieval index} is the intended fair, reproducible run mode but is \textbf{not implemented} (\texttt{FrozenIndex} raises), so every result reported here is from live retrieval, so ``New/Surprising'' reflect genuine synthesis rather than fresher retrieval, and runs are reproducible. The snapshot is released as URLs $+$ timestamps $+$ SHA-256 per-document hashes (not raw content, for licensing; see the datasheet), so any party can reconstruct and verify the exact corpus. Canary strings for post-hoc training-set detection are \textbf{planned but not present} in any of the 50 items, results are split pre/post-training-cutoff, and CREST maintains a \emph{rolling set of brand-new questions} refreshed each cycle to detect and outrun contamination. Because report length confounds LLM-judge scores, output length is a reported covariate in all analyses (\S\ref{sec:experiments}), not a free variable, and all agents receive a matched tool/compute budget.

\paragraph{Release and reproducibility.} We release the questions, schema, frozen-index manifest, judge configuration, rubric, and analysis code under a documented license, with \textbf{Croissant} $+$ Croissant-RAI metadata and a \textbf{Datasheet for Datasets} \citep{gebru2021datasheets,croissant2024} covering provenance, an author-conflict-of-interest statement, the human-study IRB/consent status, and the adversarial item-vetting log. The release is 50 items (10 per category, $\geq$8 per cell after gating); the rolling refresh rotates in fresh questions each cycle---holding $\geq$8 per cell---to outrun contamination while preserving the per-cell power of the crossover and equivalence tests (\S\ref{sec:experiments}).
