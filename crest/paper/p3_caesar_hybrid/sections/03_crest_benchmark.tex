\section{CREST}
\label{sec:crest}

\paragraph{Construct.} An output is scored on \textbf{New}, \textbf{Useful} and
\textbf{Surprising}, each rated $1$--$10$ \citep{runco2012standard,boden2004creative}. The primary
endpoint is the \emph{graded} conjunction $\min(\text{New},\text{Useful},\text{Surprising})$ on the
$1$--$10$ scale. A thresholded ``all three clear a fixed cutoff'' indicator was measured and
\textbf{withdrawn} as primary: its rate swung 5.4--36.1\% across cutoffs $5$--$7$ on the pilot, so it
is retained only for backward comparability. New is judged against a \emph{dated list of already
known answers} shipped with each question (so ``new'' means new relative to what is known, not
merely unlike web text); Useful is judged on soundness, workability, and satisfaction of the
question's hard rules; Surprising is judged relative to an \emph{expert's expected answer}, as
expectation-violation conditioned on correctness. Scoring follows the Consensual Assessment
Technique \citep{amabile1982cat,amabile1996context}. Citation accuracy is \emph{not} part of the
creativity score---it is a separate grounding check (\S\ref{sec:grounding}).

\paragraph{Task types.} Five core categories, each grounded in a mechanism from the creativity
literature:
\begin{itemize}
  \item \textbf{C1 Constrained}---invent within strict rules (bounded/exploratory creativity,
    \citealp{boden2004creative}; \citealp{simonton2003constrained}).
  \item \textbf{C2 Counterfactual}---reason about a ``what-if'' world
    (\citealp{byrne2005rational}).
  \item \textbf{C3 Cross-Domain}---connect two distant fields (structure-mapping,
    \citealp{gentner1983structure,falkenhainer1989sme}).
  \item \textbf{C4 Meta-Creativity}---invent a method, not an answer.
  \item \textbf{C5 Open-Ended}---many valid answers (transformational/blind-variation,
    \citealp{boden2004creative,campbell1960blind}).
\end{itemize}
CREST ships \textbf{50 questions---ten per task type}---spread over six domains (biology/medicine,
materials/chemistry, economics/business, law/policy, engineering, arts/humanities; eight to nine
per domain), so ``task type'' is not confounded with one specific question.

\paragraph{Stated prior expectations, \emph{not} a pre-registration.} The per-task-type prediction
(win on C2/C3, parity on C4, null on C1/C5) is recorded in
\texttt{analysis/preregistration.yaml}, and the file itself states that it is \textbf{not} an
externally timestamped registration: it was created in-repo after the code, so it cannot evidence
ordering, and there is \textbf{no} OSF or equivalent record. Nothing was confirmed on fresh,
held-out questions---there is no held-out split. Treat the directions as the authors' stated prior
expectation and nothing stronger.

\paragraph{What each question ships with.} (i) a dated list of known answers (New baseline);
(ii) any hard rules to check (Useful); (iii) an expert's expected answer (Surprising baseline);
and (iv) the predicted direction described above. See the released \texttt{schema.json} and
datasheet.

\paragraph{Two-sided prompt design.} The prompt shown to an agent is deliberately \emph{short and
open}---median $\sim$110 words---posing the task and little else. All axis-isolation and
anti-contamination machinery (rubric anchors, the known-answers and expert baselines, the planned-but-absent canary
strings, pre/post-cutoff labels) lives \emph{judge-side} and is never shown to the agent. This
preserves creative headroom, avoids over-steering the agent toward a target answer, and still keeps
grading reproducible because every scoring input is fixed and versioned.

\paragraph{Judge: three vendors, full panel, median.} Every answer is scored by an Anthropic, an
OpenAI and a Google model, and the panel score is the \emph{median} across the three. Earlier drafts
described a protocol with four properties this panel does not have. There is \textbf{no} open-weight
fourth judge. Judges are pinned by model \emph{alias}, \textbf{not} by dated snapshot, so the aliases
can silently re-point and results are time-indexed. Presentation is \textbf{not} order-randomized.
And scoring is \textbf{not} leave-one-family-out: we measured LOFO and withdrew it, because over
three vendors it makes judge identity perfectly confounded with entrant family and \emph{widens} the
between-entrant spread from $2.06$ to $3.06$ points. Self-preference is therefore handled only by
blindness plus a per-row \texttt{same\_family} stamp for post-hoc analysis, and that analysis is
\textbf{not} yet run. We report inter-judge reliability under both one-way and two-way models
(Krippendorff $\alpha$, ICC; \citealp{hayes2007alpha,koo2016icc}) together with per-judge severity,
which turns out to be the number that matters. Agreement with human experts is \textbf{not} reported
and \textbf{no} human study has been run, so humans are the primary scorer on \emph{no} category
(\S\ref{sec:limitations}).

\paragraph{Contamination and fairness controls: what exists, and what does not.} All entrants run
through their \emph{provider-native web search}, so retrieval is \emph{live} and CREST is
\textbf{not} contamination-controlled. The one anti-contamination property that does hold is
indirect: because \emph{New} is judged against per-item \emph{dated known-answers}, fresher
retrieval cannot by itself inflate the axis. Everything else earlier drafts claimed here is absent.
There is \textbf{no} open-weight entrant and \textbf{no} permanently reproducible core; there is
\textbf{no} shared, dated, hashed retrieval index, so we ship \textbf{no} URL/timestamp/SHA-256
release and \textbf{no} signed manifest, and no party can reconstruct the corpus a run saw.
Contamination canaries and a rolling refresh set are \textbf{not implemented}: zero of the 50 items
embed a canary string. Items carry a time-sensitivity label, but \textbf{no} released analysis splits
results on training cutoff. Entrants do \textbf{not} receive a matched tool and compute budget:
realised searches per item run from $0.64$ (\texttt{gemini\_shallow}, zero searches on $40$ of $50$
items) to $76.28$ (\texttt{gemini\_deepresearch\_max}), so depth is confounded with vendor.
