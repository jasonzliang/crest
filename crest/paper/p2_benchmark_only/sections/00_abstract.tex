\begin{abstract}
Deep-research web agents now write long, cited reports, and a wave of benchmarks scores whether those reports are accurate, comprehensive, and faithfully cited. None asks whether they are \emph{creative}. We introduce \textsc{CREST} (CREativity of reSearch agenTs), the first released benchmark for the creativity of deep-research agents. Each grounded output is scored on whether it is \emph{New}, \emph{Useful}, and \emph{Surprising}---each rated $1$--$10$, and an output counts as creative only if all three clear a threshold---an operationalization of the standard definition of creativity \citep{runco2012standard} augmented with Boden's surprise criterion \citep{boden2004creative}. CREST comprises 50 expert-authored challenges---10 per category---spanning five creative-process categories (constrained, counterfactual, cross-domain, meta, and open-ended synthesis) and six domains; each ships with a dated known-answers list (the baseline for \emph{New}), checkable hard rules (the reference for \emph{Useful}), and an expert baseline (the reference for \emph{Surprising}). The agent sees only a short, open prompt; all of this axis-isolating machinery is held judge-side, preserving creative headroom while keeping grading reproducible. Entrants run under their provider-native web search, and a frozen, shared retrieval index gives a fair, reproducible, contamination-controlled run mode. Scoring uses a human-validated, leave-one-family-out, median-aggregated multi-vendor judge panel (with dated, pinned model snapshots) plus a factual-grounding check, so novelty earns credit only when its factual scaffolding is supported---inverting the corpus-overlap and diversity metrics that reward a confabulator over a faithfully cited agent \citep{lu2024creativityindex,saakyan2026death,zhang2025noveltybench}. Evaluating a field of frontier deep-research agents, we find that agent creativity is \emph{axis- and task-dependent} and dissociates across systems: the pattern is theory-predicted (cross-domain and counterfactual synthesis are aligned with structure-mapping and counterfactual reasoning \citep{gentner1983structure,byrne2005rational}). We release the challenges, judge harness, frozen snapshots, and datasheet.
\end{abstract}
