Historical runs

The run format notes and aborted-run explanations remain in Git. The underlying data in research/result/ stay on disk; a fresh clone does not include them. Both result/ and results/ directories are ignored throughout this repository.

The earlier protocol used absolute creativity scores, grounding checks, and panel summaries. These historical results are not inputs to the current pairwise rankings. Archived scripts retain their original imports and dependency assumptions; they are reference code.
