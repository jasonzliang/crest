Judge Models

Claude Opus 5.5, GPT-6.1 Sol and Gemini 4 Argon are the current judges. All use high reasoning, thinking or effort to compare each available answer pair in both orders, returning one overall A/B winner and a comparative explanation. Opus uses the LiteLLM gateway; Sol and Argon use their direct provider APIs. This page records active request settings and cost assumptions, not new benchmark results.

The active inputs are crest/data/queries_n50_v2.jsonl and crest/prompts/nus_pairwise_v3.txt. The default NUS rubric and optional AUT-inspired rubric define the criteria. See the research ranking method or paper comparison method for how choices become results.

Judges receive complete answer text without tools or provider labels. URL destinations are hidden while meaningful citation labels remain. Wording can still reveal the authoring system. Response checks reject obvious noncomparisons and unfinished explanations. The research pipeline allows up to four attempts by default; the paper pipeline records invalid paid responses without automatically resubmitting them. A Claude refusal fails the attempt and is retried like any other rejected judge response. These checks do not verify facts or whether the explanation supports the winner. Judge costs are additional

With all five current research providers, a complete 50-question run would require 1,000 valid judgments per judge (50 questions × 10 pairs × 2 orders), or 3,000 across the three judges; retries can add paid calls. The earlier four-system design required 600 per judge, and the completed three-system/two-judge study retains its 600 total judgments. These design counts do not imply a new run has completed. The 32,768-token allowance includes reasoning or thinking and does not predict usage. Judge spending is additional to generation budgets.

Shared models, shared limitations

Caesar uses Sol at medium reasoning for main research and high for synthesis drafts and merge. Its exploration and knowledge-base helpers use Luna/low; OpenAI research uses Sol/high. Anthropic research uses Opus 5.5/high through LiteLLM, the same model, effort and gateway token tariff as the Anthropic judge. Research runs client-side search and fetch, so it pays no per-search fee. Google retains its standard managed Deep Research agent. Shared model families and different researcher/judge IDs do not establish independent errors or eliminate provider and style preferences.

Caesar’s $2.60 reserve applies only in hard/auto mode, not current soft mode. Finite work/token/time limits and accounting remain; hard-only admission checks do not. See the research configurations for details.

GPT Researcher: Sol/high for all roles, 32,000 research/writer tokens, $3.40 planning target, $0.50 synthesis allowance and soft $4 warning. Answer concurrency is 4 → 8, like Caesar; inner concurrency remains 2. Use the isolated worker described in the setup guide.

Anthropic research uses client DDGS search and HTTP fetch, not unsupported native web search. Bootstrap retrieval must produce usable evidence before the first paid model call. Retrieval has no API fee; model tokens remain billed. OpenAI hosted search is separately billed. Judges use no tools.

Google pricing assumptions / sensitivity

Both Google figures use the same conditional estimator: high-context rates, tool-use tokens counted as extra input, and full-price searches. The historical 600-word v2 profile totals $146.0447 across 50 answers, or $2.9209 per answer. Applied to the new uncapped q1, that pricing scenario gives $6.9990348. Neither is a verified bill; the q1 figure is not a confirmed overrun or current mean. See the historical v2 cost records.

Research answers have no word cap. Output-token and finite-work limits still apply; recorded word counts are descriptive. Historical 600-word studies retain their original settings.

Research budgets: all five are soft $4 warnings. OpenAI and Anthropic run a fixed number of follow-up rounds sized to land near $3 (OpenAI 5 rounds, Anthropic Opus 7); a follow-up is skipped only if one as costly as the last would pass $4; GPT uses the $3.40/$0.50 planning settings above.
