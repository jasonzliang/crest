# AI Scientist Benchmark Artifacts

## Description

This dataset contains artifacts generated by seven AI scientist systems on one research topic.

Each package corresponds to one topic.
Each topic package includes the outputs from seven AI scientist systems under the same task setting.

Current release contains one topic. More topics will be added later.

## Included AI Scientist Systems

* EvoScientist
* Auto Research Claw
* Deep Scientist
* AI Researcher
* ARIS
* The AI Scientist v2
* Dr. Claw

## Dataset Structure

```text
topic_name/
├── inputs/
│   ├── evoscientist/
│   ├── auto_research_claw/
│   ├── deep_scientist/
│   ├── ai_researcher/
│   ├── aris/
│   ├── the_ai_scientist_v2/
│   └── dr_claw/
├── outputs/
│   ├── evoscientist/
│   ├── auto_research_claw/
│   ├── deep_scientist/
│   ├── ai_researcher/
│   ├── aris/
│   ├── the_ai_scientist_v2/
│   └── dr_claw/
└── metadata.json
```

## Data Content

Each topic package contains:

* task input for each AI scientist system
* generated reports
* generated code or scripts
* experiment logs
* submission files, if available
* evaluation results, if available

## Metadata

Each topic package should include a `metadata.json` file:

```json
{
  "topic_id": "1",
  "topic_name": "NLP-TASK",
  "task_name": "BABYLM",
  "agents": [
    "EvoScientist",
    "Auto Research Claw",
    "Deep Scientist",
    "AI Researcher",
    "ARIS",
    "The AI Scientist v2",
    "Dr. Claw"
  ],
  "release_status": "partial"
  
}
```

## Intended Use

This dataset is intended for evaluating and comparing AI scientist systems.

It can be used to study:

* whether an AI scientist can complete a research task
* what artifacts it produces
* where it fails
* how different AI scientist systems behave on the same topic
