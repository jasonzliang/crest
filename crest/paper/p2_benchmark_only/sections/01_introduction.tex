\section{Introduction}

Deep-research agents---LLM systems that autonomously browse the web and synthesize long, cited reports---are evaluated by a fast-growing set of benchmarks. Yet every one of them scores the same four things: factual \emph{accuracy} \citep{mialon2023gaia,wei2025browsecomp}, \emph{coverage}/recall, citation \emph{faithfulness} \citep{du2025deepresearchbench}, or task \emph{completion}. The axis on which a \emph{research} agent's scientific and economic value actually concentrates---the ability to surface a \emph{creative} synthesis, a non-obvious and useful connection a reference-matching agent would be penalized for---is unmeasured. The two benchmarks that use the word ``insight'' score it \emph{against a gold reference report} \citep{du2025deepresearchbench,researcherbench2025}, which structurally penalizes surprise. Creativity has been measured only for \emph{ungrounded} idea generation by base LLMs \citep{si2024novel,ruan2024liveideabench}---no web retrieval, no evidence synthesis, no citation grounding. The intersection---creativity of a web-grounded deep-research agent's output---is empty. That is what \textsc{CREST} measures.

\paragraph{Relationship to prior work.} A workshop preprint piloted a five-category, New/Useful/Surprising creativity evaluation on a single agent \citep{caesar2026}. CREST is not that pilot rerun: our contribution is (i) a \emph{released, versioned} benchmark (50 expert-authored challenges, 10 per category, $\times$ 6 domains, vs.\ five single queries), (ii) a judge characterised by measured severity and reported reliability bounds rather than assumed sound, and (iii) a \emph{cross-agent} measurement over five commercial entrants rather than one system. The pilot agent is \textbf{not} an entrant here: no run in this artifact contains records for it, and no result below concerns a system the authors built.

\paragraph{Contributions.}
\begin{enumerate}
  \item \textbf{Finding (methodological, and negative).} Judge-severity variance dominates the signal this benchmark was built to produce: per-axis severity spans $3.32/3.20/3.74$ points against a $2.06$-point spread between the best and worst entrant, so the leaderboard is \textbf{unidentifiable} and we make no ranking claim (\S\ref{sec:experiments}). The agent$\times$category interaction is \textbf{null} ($F=0.654$, $p=0.837$); an earlier draft claimed a theory-predicted crossover in which no single creativity scalar orders agents, and that claim is withdrawn.
  \item \textbf{CREST.} The first released creativity benchmark for deep-research agents: New/Useful/Surprising (each 1--10) over five creative-process categories $\times$ six domains (50 challenges, 10 per category), with per-item dated known-answers, hard rules, and expert baselines held judge-side behind a short, open agent prompt. Retrieval is live: there is \textbf{no} frozen shared index, and the corresponding code path raises rather than pretending to provide one.
  \item \textbf{A bounded judge.} A multi-vendor judge panel with a factual-grounding check, reported with per-category reliability, measured per-judge severity, and honest bounds on where it fails. Human validation is \textbf{future work}: we make no judge--human agreement claim. We score with the \emph{full} panel and retain leave-one-family-out only as a robustness check, because over three vendors it assigns judge panels by entrant family.
\end{enumerate}
