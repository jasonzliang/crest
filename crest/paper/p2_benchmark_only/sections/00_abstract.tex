\begin{abstract}
Deep-research web agents now write long, cited reports, and a wave of benchmarks scores whether those reports are accurate, comprehensive, and faithfully cited. None asks whether they are \emph{creative}. We introduce \textsc{CREST} (CREativity of reSearch agenTs), the first released benchmark for the creativity of deep-research agents. Each grounded output is scored on \emph{non-redundancy} against a dated prior-art set, \emph{usefulness} against checkable rules, and---exploratorily---\emph{surprise}, each rated $1$--$10$, with $\min$(non-redundancy, usefulness) as the primary endpoint. We name the first axis for what it measures rather than calling it novelty: an unanchored novelty rating is directionally wrong, not merely noisy (LLM judges rate generated content as highly novel where domain experts conclude the opposite), and our own ablation reproduces this---withholding the prior-art set inflates the axis by $+0.98$. The same ablation shows the expert baseline moved surprise by $-0.02$, so we withdraw it from the judge and report two primary axes rather than three: this operationalizes the standard definition of creativity \citep{runco2012standard}, with Boden's surprise criterion \citep{boden2004creative} retained as an exploratory axis we show is not separable ($r\approx0.95$). CREST comprises 50 expert-authored challenges---10 per category---spanning five creative-process categories (constrained, counterfactual, cross-domain, meta, and open-ended synthesis) and six domains; each ships with a dated known-answers list (the baseline for \emph{New}), checkable hard rules (the reference for \emph{Useful}), and an expert baseline (the reference for \emph{Surprising}). The agent sees only a short, open prompt; all of this scoring machinery is held judge-side, preserving creative headroom while keeping grading reproducible. We label each item with the N/U/S axis it was designed to stress, but report that the label validates only for \emph{usefulness} on the constrained category (the labelled axis is the binding one in 56\% of those records against a 33\% chance rate); the novelty and surprise labels are design intent the data does not confirm. Entrants run under their provider-native web search. Retrieval is therefore \emph{live} and the benchmark is \textbf{not} contamination-controlled; a frozen, shared retrieval index is future work, so results are time-indexed snapshots. Scoring uses a multi-vendor judge panel (\textbf{not} yet human-validated; a human study is future work) scored by the full panel, with leave-one-family-out retained as a robustness check rather than the primary protocol (with dated, pinned model snapshots) plus a factual-grounding check, so novelty earns credit only when its factual scaffolding is supported---inverting the corpus-overlap and diversity metrics that reward a confabulator over a faithfully cited agent \citep{lu2024creativityindex,saakyan2026death,zhang2025noveltybench}. Evaluating a field of frontier deep-research agents, our headline result is \emph{methodological}: judge-severity variance dominates the between-agent spread, and leave-one-family-out over a three-vendor panel assigns judge panels by entrant family, which makes such a leaderboard \textbf{unidentifiable}. We therefore report per-axis profiles under a common panel and make no ranking claim. We further find that \emph{New} and \emph{Surprising} are not separable in practice ($r\approx0.93$), so we report two primary axes and treat surprise as exploratory. We release the challenges, judge harness, per-judge scores, and datasheet.
\end{abstract}
