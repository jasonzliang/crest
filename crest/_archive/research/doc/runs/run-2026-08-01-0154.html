Which file is which

file produced by contains
transcripts.jsonl the AGENTS what each agent actually wrote: output_text + citations
records.jsonl the JUDGES the scores: per-axis New/Useful/Surprising, per-judge rows, grounding verdict, scoring_status
errors.jsonl the harness tasks that produced no record at all
summary.json the harness per-agent and per-agent-x-category aggregates
run_manifest.json the harness provenance; written last, so it marks completion

The names are historical: "records" is the judge output and "transcripts" is the agent output, which is the reverse of what most readers assume. Join them on record_id.

import json
scores = {r["record_id"]: r for r in map(json.loads, open("records.jsonl", encoding="utf-8"))}
answers = {t["record_id"]: t for t in map(json.loads, open("transcripts.jsonl", encoding="utf-8"))}
rid = next(iter(scores))
print(scores[rid]["agent"], scores[rid]["creativity"]["new"], answers[rid]["output_text"][:200])

Reading the scores

creativity is null on every UNSCORED path -- but judge_degraded is the exception: it carries a full creativity dict scored by too few judges. Filter on scoring_status == "scored", NOT on creativity is not None, or degraded rows land in your headline means. Other statuses: judge_degraded (fewer judges than min_judges survived), empty_answer (the agent returned literally nothing -- an ADAPTER failure, not a grounding failure), too_short (non-empty but under the substantive-length floor; same adapter root cause, but the threshold is a judgement call and the emptiness is not), grounding_fail, judge_error. Per-axis values are the MEDIAN across the judges in creativity.judges; each judge row carries same_family, so the leave-one-family-out subset is recoverable by filtering those rows out.
