Method

This is an adversarial item-vetting pass over all 50 CREST challenges in question/crest_challenges.jsonl (ids ending 00–29 are the 30 original items; 30–49 are the 20 newly-added items). Each item was read in full — query, hard_rules, known_answers, expert_baseline, and (at the time) the per-item predicted_direction and designer rationale — and stress-tested against five gates. The goal is not to re-grade a model's answer but to ask whether each item actually measures what it claims to. Gates are marked PASS / WEAK / FAIL; each item gets a disposition (KEEP / REVISE / CUT) with a one-line reason. This report does not modify the dataset.

The five gates:

  1. G1 Contamination-resistance — is the answer NOT memorizable / not sitting on a single indexed page (genuinely multi-hop)? All items are invention or counterfactual tasks with no canonical published answer, and each known_answers list deliberately pre-claims the memorizable/first-order content, forcing work beyond recall. (→ SUPERSEDED in strength: this was judged by reading. The decisive test — a tool-ablation check, scoring a no-web model and cutting anything it answers — has never been run, and runs are live-web, not contamination-controlled. Read every G1 PASS as "no memorizable answer was apparent", not as measured.)
  2. G2 Synthesis-required — does answering truly need multi-source synthesis rather than a single lookup?
  3. G3 Axis-isolation — does it genuinely exercise its labeled isolated axis (C1 usefulness, C2 surprise, C3 novelty, C4 balanced, C5 novelty) rather than a confound?
  4. G4 Headroom — is it hard enough not to be saturated by a strong agent (not trivially answerable)?
  5. G5 Metadata — known_answers dated & non-empty, hard_rules checkable, expert_baseline present. (→ SUPERSEDED: the "dated" half of this gate was graded by inspection and is wrong at file scale — see the header and datasheet.md §2. Every G5 PASS below should be read as "non-empty and present", never as "dated".)

  • C5_economics_business_46, C5_law_policy_47, C5_engineering_48, C5_arts_humanities_49 (G2/G3/G4 WEAK) — this lightweight C5 subset is a distinctly easier tier than the C5 originals: only 3 hard rules, short deliverables, and a novelty check that is pure negative-verification ("confirm no established X does this") rather than genuine multi-source synthesis. Systematic patterns

  • By gate.
    • G1 (contamination): uniformly strong on inspection. The invention/counterfactual format plus known_answers lists that pre-claim the memorizable and first-order content make the whole set look genuinely multi-hop; no item was found answerable from a single indexed page. → SUPERSEDED as a measurement: no tool-ablation check was run, and runs use live web search with no frozen index, so search-time contamination is uncontrolled and unmeasured.
    • G2 (synthesis): strong except the C5 lightweight subset (46–49). C5 as a category leans on "prove absence" negative-verification, which is thinner synthesis than the literature-fusion demanded by C1/C3/C4; the C5 originals (24–29) compensate with rich prior-art surveys, but 46–49 do not.
    • G3 (axis-isolation): solid across the board. Note two inherent (well-mitigated) entanglements: C3's "novelty" overlaps "surprise" (a novel structural mapping is also surprising) — handled by explicit novelty gates + expert baselines; and the C1 arts/invention items (05, 33) lean novelty-adjacent — handled by concrete functional/usefulness checks. Only 46–49 are genuinely WEAK (novelty labeled but the bar can't separate genuine from arbitrary novelty). → SUPERSEDED twice over. (a) The "handled by … expert baselines" mitigation no longer operates: expert_baseline is judge-hidden as of 2026-07-30 because ablating it barely moved Surprising, and New and Surprising correlate hard in the run data. That correlation is CONTAMINATED — the v1 judge prompt stated it to the judge — so it does not license the conclusion "the axes do not dissociate", which an earlier version of this line drew. Figures and caveat: design.md §0. (b) The axis labels were measured against judge verdicts and mostly do not bind: valid for C1/usefulness only, wrong-signed for novelty. Rates: design.md §0. The 56% / 21% / 15% previously quoted here came from superseded run 111856Z (n=196).
    • G4 (headroom): C1/C3/C4 are the hardest tiers and clearly unsaturated; only 46–49 are saturable.
    • G5 (metadata): all known_answers are dated & non-empty → FALSE, see header. known_answers is non-empty everywhere (8–33 entries per item) and hard_rules are checkable (5–12 rules per item in the shipped file), but most prior-art entries carry no year, and the _3x/_4x half of the file is far worse than the first half — rates in datasheet.md §2. One hard FAIL at the time (09, broken expert_baseline) — since fixed; a second (34) was found later by schema enforcement.
  • Missing category_name in every new item. → MOOT. category_name was removed from all 50 items in schema v2.0.0 (it was derivable from category, and one item shipped a long-form value that made groupby yield six categories). There is nothing to backfill.
  • Self-flagged unverified known_answers. Three items (01, 05, 15) noted that the web-search budget was exhausted before verification. → Now resolved by the live audit: 15 is fully verified (all 10 prior-art entries check out); 05 and 33 and 32 came back clean; 01's Cs₂TiI₆ band gap is half-corroborated (the 1.56 eV direct figure holds; the indirect figure does not reproduce) and it retains two IMPRECISE entries plus the two blocking rule contradictions above.

Strongest = C3 (equation/theorem-level fidelity, highest headroom) and C4 → SUPERSEDED on C4. C3's own standing is also qualified — the audit found five mathematical errors in C3 hard rules and one materially wrong novelty gate (_17), though it confirmed zero fabrications across ~155 checked claims.

Do the newly-added items (30–49) hold up as well as the originals?

→ SUPERSEDED. The answer measured by the live audit is: no. The desk pass concluded "mostly yes", reasoning that the new C1 (30–33), C2 (34–37), C3 (38–41) and C4 (42–45) items reuse the originals' isolation logic — checkable feasibility envelopes, anti-obvious coherence rules, well-anchored expert baselines, novelty gates — and graded them PASS on all five gates. Two things that reading could not see turned out to separate the halves of the file:

  1. The citation cliff. Prior-art dating collapses from the _1x block to the _3x/_4x blocks (rates: datasheet.md §2). Whoever wrote the back half of the file stopped citing, and an undated bare name cannot gate novelty at all — a judge cannot ask "absent as of date D" when D is unstated.
  2. Gate inversion. _45's hard rule offers as its example of a new mechanism something its own prior-art list already implements, and its baseline asserts the opposite of the truth, so the gate awards novelty for reproducing published prior art. _42 and _43 have milder versions.

The C5 lightweight subset (46–49) — the one weakness this pass did catch — has since been hardened. The metadata regressions it named have both closed: category_name no longer exists on any item, and 09's placeholder baseline was replaced. They were replaced by different ones: 34's baseline is model-drafted, and _3x/_4x prior art is largely undated.
