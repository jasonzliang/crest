\section{Limitations}
\label{sec:limitations}

An earlier version of this section presented a judge$\leftrightarrow$human disagreement on C1/C5 as a
candid weakness, described component ablations that were never run, claimed settings that are
\emph{not} human-validated, and named an open-weight entrant on a frozen index as the ``permanently
reproducible core.'' None of those things exists. Presenting an unperformed study \emph{as a limitation} is worse than omitting it, because it
buys credit for candour while adding a false claim. That text is withdrawn. Below are the limitations
the artifact actually has.

\paragraph{The leaderboard is unidentifiable, and this dominates everything else.} Per-axis judge
severity spans $3.32/3.20/3.74$ points on a $1$--$10$ scale while the entire spread between best and
worst entrant is $2.06$ points. No ordering can be read off this run for any entrant. It is a property
of the instrument, not of the entrants, and no analysis of the existing data repairs it.

\paragraph{The primary endpoint is largely hard-rule compliance.} $\mathrm{corr}(\min(N,U,S), U) =
0.976$; the composite \emph{equals} Useful in $190$ of $250$ records; \emph{New} is the unique minimum
in $1$ of $250$. Since a violated hard rule caps Useful at ${\leq}3$, the endpoint behaves close to a
rule-violation indicator, and the between-category ordering tracks constraint density rather than
creative process. We cannot currently claim it measures creativity as distinct from constrained
generation.

\paragraph{Judge blindness leaks.} Provider search tools stamp their own URLs
(\texttt{?utm\_source=openai}; \texttt{vertexaisearch.cloud.google.com} redirects), and those strings
survive into the report text the judge is shown. $143$ of $250$ records ($57\%$) carry a
machine-readable vendor fingerprint. Because leave-one-family-out was withdrawn, blindness was the
only active self-preference control, so self-preference here is live and unmeasured. The fix is to
canonicalise URLs and re-judge; it has not been done.

\paragraph{No human validation.} No human-expert study has been run: no
judge$\leftrightarrow$human agreement, no human--human ceiling, no human-anchored category. Every
score here is an LLM-judge score. We estimate the study at ${\sim}\$1$--$3$k and have not begun it.

\paragraph{Poor absolute agreement, and a post-hoc model choice.} One-way $\mathrm{ICC}(1,k)$ is
$0.0/0.618/0.0$; Krippendorff's $\alpha$ is the same statistic as $\mathrm{ICC}(1,1)$ for interval
data, so those are one control reported twice. The two-way model that removes the judge main effect
gives $0.736/0.807/0.759$---but it was chosen \emph{after} seeing the data and is exploratory.

\paragraph{\emph{Surprising} is unanchored and its correlation with \emph{New} is contaminated.} The
expert baseline was withdrawn from the judge prompt after an ablation moved the axis by only $-0.02$,
so the axis rests on the judge's own prior---and \textbf{that ablation is not reproducible against this
release}, so the justification for the withdrawal is unchecked. It was measured on a superseded run no
longer on disk, no per-arm judge scores were persisted, and all $250$ released records carry
\texttt{judge\_prompt\_version: null}, so \texttt{analysis/ablate\_fields.py} refuses to run against
them by design. The same applies to the $+0.98$ known-answers delta quoted for \emph{New}, whose stated
baseline ($7.28$ over $50$ records) is inconsistent with this run's $8.14$ over $250$. Separately, $r =
0.883$ cannot argue the axes are inseparable, because the judge prompt for this run stated a
correlation to the judge. A clean estimate needs re-scoring, which has not been done.

\paragraph{No mechanism evidence.} The exploration agent was never entered
(\S\ref{sec:caesar}), so there is no single-agent mechanism claim to scope---there is no mechanism
claim at all. The five commercial entrants differ in model, search budget and research loop
simultaneously, so no comparison among them isolates a component.

\paragraph{Budgets are not matched, and generation provenance is not uniform.} Realised searches per
item run from $0.64$ (\texttt{gemini\_shallow}, zero searches on $40$ of $50$ items) to $76.28$
(\texttt{gemini\_deepresearch\_max}, max $144$), so depth is confounded with vendor rather than
controlled, and no cost--creativity frontier is reported. Separately, $196$ of the $250$ generations
were served from a content-addressed cache populated by three earlier runs at two different commits;
only \texttt{claude\_shallow} was generated entirely fresh. Cache reuse is therefore unbalanced across
entrants and its effect on scores is unmeasured.

\paragraph{Length is not controlled, and is not measured.} Output length is \textbf{not} recorded for
this run: zero of the $250$ records carry \texttt{answer\_chars} or \texttt{answer\_words}. The only
stored size field is the provider's billed token count, which includes invisible reasoning tokens and
is not comparable across arms, so a length covariate is not computable from this release at all.

\paragraph{The registered equivalence test cannot fire.} TOST as registered compares a category
composite against a reference of $0$ with bounds of $\pm1$ on a $1$--$10$ scale, which no category can
satisfy. Three of five categories carry null or parity predictions (C1/C5 null, C4 parity), so those predictions are
untestable as registered and are reported descriptively.

\paragraph{Not reproducible, and not contamination-controlled.} The $250$-record run directory is not
distributed, so the reported table cannot be recomputed from a fresh clone. Retrieval is live, so no
re-run reproduces these numbers. The frozen-index code path deliberately raises rather than
pretending to provide one. Entrants are pinned by model alias, not dated snapshot, so results are
time-indexed and the aliases can silently re-point.

\paragraph{Overlap with the companion preprint, and the anonymity risk it creates.} The exploration
agent and an early version of the taxonomy appear in a prior preprint by (anonymized) authors
\citep{caesar2026}. Because this paper cites that preprint \emph{and} describes the cited system as
its authors' own, the anonymisation is structurally weak. The contribution claimed here is the
benchmark artifact and the negative methodological result, not the agent.
