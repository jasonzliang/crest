\section{Creative \emph{and} Grounded: the Factual-Grounding Check}
\label{sec:grounding}

A creativity benchmark must not reward confabulation. We therefore apply a \emph{factual-grounding check} to every agent's CREST outputs, cross-agent, using established attribution metrics \citep{gao2023alce,rashkin2023ais,min2023factscore} and the DeepResearch Bench FACT score \citep{du2025deepresearchbench}. The check targets an answer's \emph{factual scaffolding}---its load-bearing factual claims---not the creative artifact itself: if that scaffolding is not attributable to the cited sources, the output is disqualified for creativity (creativity score $=0$), whereas a genuine invention is \emph{never} penalized merely for lacking a citation for the invented idea. The production check is a per-claim FACT verifier. This operationalizes ``\emph{Useful} gates \emph{New}'' and closes the novelty-by-hallucination exploit that sinks corpus-novelty metrics (\S\ref{sec:related}).

Because the check zero-inflates the score distribution, we model creativity with a two-part (hurdle) model---a pass component and a conditional-creativity component---rather than assuming normality. We validate the check's precision/recall against human faithfulness labels, report its per-agent firing rate (to detect differential firing), and run a with/without-check sensitivity analysis. This section is computed on the \emph{same} reports scored for creativity, so ``creative and well-sourced'' is shown jointly and across all agents---not as a single-system showcase.
