\section{Introduction}

Deep-research agents---LLM systems that autonomously browse the web and synthesize long, cited reports---are evaluated by a fast-growing set of benchmarks. Yet every one of them scores the same four things: factual \emph{accuracy} \citep{mialon2023gaia,wei2025browsecomp}, \emph{coverage}/recall, citation \emph{faithfulness} \citep{du2025deepresearchbench}, or task \emph{completion}. The axis on which a \emph{research} agent's scientific and economic value actually concentrates---the ability to surface a \emph{creative} synthesis, a non-obvious and useful connection a reference-matching agent would be penalized for---is unmeasured. The two benchmarks that use the word ``insight'' score it \emph{against a gold reference report} \citep{du2025deepresearchbench,researcherbench2025}, which structurally penalizes surprise. Creativity has been measured only for \emph{ungrounded} idea generation by base LLMs \citep{si2024novel,ruan2024liveideabench}---no web retrieval, no evidence synthesis, no citation grounding. The intersection---creativity of a web-grounded deep-research agent's output---is empty. That is what \textsc{CREST} measures.

\paragraph{Relationship to prior work.} A workshop preprint piloted a five-category, New/Useful/Surprising creativity evaluation on a single agent \citep{caesar2026}. CREST is not that pilot rerun: our contribution is (i) a \emph{released, versioned, contamination-controlled} benchmark (50 expert-authored challenges, 10 per category, $\times$ 6 domains, vs.\ five single queries), (ii) a judge whose validity against human experts is itself a first-class, reported result, and (iii) a \emph{cross-agent} finding---a claim about the capability frontier, not one system. We report the pilot agent as one entrant among many and de-emphasize its ranking.

\paragraph{Contributions.}
\begin{enumerate}
  \item \textbf{Finding.} Deep-research-agent creativity is axis/task-dependent and dissociates across the frontier: no single ``creativity'' scalar orders agents; the most-creative agent on one axis is not the most-creative on another (a theory-predicted crossover, \S\ref{sec:experiments}).
  \item \textbf{CREST.} The first released creativity benchmark for deep-research agents: New/Useful/Surprising (each 1--10) over five creative-process categories $\times$ six domains (50 challenges, 10 per category), with per-item dated known-answers, hard rules, and expert baselines held judge-side behind a short, open agent prompt, and a frozen shared index for fair, reproducible runs.
  \item \textbf{A validated judge.} A human-validated, leave-one-family-out judge panel with a factual-grounding check, reported with per-category reliability and honest bounds on where it fails.
\end{enumerate}
