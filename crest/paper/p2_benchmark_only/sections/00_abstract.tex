\begin{abstract}
Deep-research web agents now write long, cited reports, and a wave of benchmarks scores whether those reports are accurate, comprehensive, and faithfully cited. None asks whether they are \emph{creative}. We introduce \textsc{CREST} (CREativity of reSearch agenTs), the first released benchmark for the creativity of deep-research agents. Each grounded output is scored $1$--$10$ on \emph{New} against a dated known-answers list, \emph{Useful} against checkable rules, and \emph{Surprising} against expert expectation, with the graded conjunction $\min$(New, Useful, Surprising) as the primary endpoint. We name the first axis for what it measures rather than calling it novelty: an unanchored novelty rating is directionally wrong, not merely noisy (LLM judges rate generated content as highly novel where domain experts conclude the opposite), and our own ablation reproduces this---withholding the prior-art set inflates the axis by $+0.98$. CREST comprises 50 expert-authored challenges---10 per category---spanning five creative-process categories (constrained, counterfactual, cross-domain, meta, and open-ended synthesis) and six domains; each ships with a dated known-answers list (the baseline for \emph{New}) and checkable hard rules (the reference for \emph{Useful}). The agent sees only a short, open prompt (median 110 words); all scoring machinery is held judge-side, preserving creative headroom while keeping grading reproducible. That asymmetry is the design contribution.

Entrants run under their provider-native web search, so retrieval is \emph{live} and the benchmark is \textbf{not} contamination-controlled: there is \textbf{no} frozen shared index---that is future work, and the corresponding code path deliberately raises rather than pretending to provide it. Scoring uses a three-vendor panel with median aggregation, \textbf{not} human-validated---no human study has been run---and \textbf{not} leave-one-family-out: we measured LOFO and withdrew it, because over three vendors it makes judge identity perfectly confounded with entrant family and \emph{widens} the between-entrant spread from $2.06$ to $3.06$ points.

Our headline result is \emph{methodological and negative}. Judge-severity variance dominates: per-axis severity spans $3.32/3.20/3.74$ points against a between-entrant spread of $2.06$, so the leaderboard is \textbf{unidentifiable} and we make no ranking claim. One-way inter-rater agreement is poor---$\mathrm{ICC}(1,k)$ of $0.0/0.618/0.0$---while the two-way model that removes the judge main effect gives $0.736/0.807/0.759$, so the panel ranks answers far more consistently than it scores them; we report both, because either alone misleads. \emph{New} and \emph{Surprising} correlate at $r=0.883$, but that figure is \textbf{contaminated}---the judge prompt used for this run stated a correlation to the judge---so we do not claim the axes are inseparable, and \emph{Surprising} is the uniquely lowest axis in $20\%$ of records. Across five entrants, task type moves scores more than entrant identity does ($2.92$ vs $2.06$ points), \emph{Useful} is the binding axis, and the agent$\times$category interaction is \textbf{null} ($F=0.654$, $p=0.837$): we find no evidence for the rank-reversal an earlier draft claimed. We release the challenges, judge harness, per-judge scores, promoted results and datasheet, and state plainly what is not reproducible: the run directory is not distributed and retrieval is live.
\end{abstract}
